## Archive policy

- Retain original design notes with stable paths so existing source citations and Git history do not break.
- Keep current guidance and regression-test documentation discoverable through this index; use new dated notes for changes.
- Never delete old project-field mappings, migrated screen IDs, source workbook records, A–E assessment guidance or future-cohort preparations to make an archive appear shorter.
- A merged feature branch may be deleted after its PR, head SHA and merge ancestry are verified; the merged commits and original PR remain available in GitHub.

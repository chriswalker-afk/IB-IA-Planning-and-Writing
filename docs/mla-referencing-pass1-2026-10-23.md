# MLA referencing guide – Pass 1 (23 October 2026)

A featured, searchable MLA citation tutorial has been added to Tools & Tutorials. Its single recommended workflow uses Google Docs > Tools > Citations > MLA (8th ed.), followed by Insert bibliography and an edited Works Cited list. The interactive worked example uses the World Bank's real Population, total indicator as a **reference demonstration**, not invented student research. Eight collapsible cases cover published data, common course mathematics, unfamiliar methods, original work, photographs, paraphrases and AI-generated material. Links use an approved host allowlist. This tutorial does not write to the student project.

Pass 2 will add contextual Writing/Planning prompts. Pass 3 strengthens the existing D09 review. Pass 4 audits illustrative IA samples.
